One funny single-line diagnosis an AI therapist hands its human, 200 characters or less.

> Diagnosis: chronic unread-message anxiety. You leave 214 chats on read, then rehearse apologies in the shower. Homework: reply to one — starting with your mother.

The joke: a clinical setup (diagnosis, homework) collides with an ordinary habit — leaving chats on read — and the prescription is the punchline.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` — 162 characters, one line, no trailing newline.
